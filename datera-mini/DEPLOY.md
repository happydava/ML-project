# Бесплатный деплой DATERA EDU mini

Проект запускает три нейросети (Whisper, WavLM, MiniLM) на процессоре, поэтому нужен хостинг с большим объёмом
оперативной памяти. Бесплатные тарифы Render, Railway и Fly.io дают 256–512 МБ, этого не хватит даже для PyTorch.
**Подходит Hugging Face Spaces**: бесплатный CPU Basic (2 vCPU, 16 ГБ RAM), контейнер Docker, публичная ссылка.

## Деплой на Hugging Face Spaces

1. Зарегистрируйтесь на https://huggingface.co (бесплатно).
2. Нажмите **New → Space**. Имя любое, **SDK: Docker → Blank**, оборудование **CPU basic (free)**, доступ Public или Private.
3. Загрузите файлы проекта в Space. Самый простой способ: на странице Space выберите **Files → Add file → Upload files** и перетащите содержимое
   папки проекта (Dockerfile, README.md, requirements.txt, папки `datera`, `web`, `sample`, файл `cli.py`). Папки `.venv`, `data`, `out` не нужны.
   Либо через git: `git clone` адреса Space, скопируйте файлы, `git add . && git commit && git push`.
4. Откройте **Settings → Variables and secrets** и добавьте:
   - Secret `DATERA_PASSWORD` – пароль, который получат демо-аккаунты (teacher@datera.test, student@datera.test, parent@datera.test, admin@datera.test).
   - Variable `DATERA_DEMO` = `0` – скрыть кнопки демо-входа на публичной странице (тогда входить только по почте и паролю). Для показа преподавателю можно оставить пустым: кнопки останутся.
   - Secret `DATERA_LLM_API_KEY` – ключ языковой модели (например, Groq: https://console.groq.com/keys). Тогда ключ не нужно вводить в админ-панели.
5. Space соберёт образ (10–20 минут при первой сборке: скачиваются PyTorch и все модели). Потом приложение будет доступно по адресу
   `https://<ваш-логин>-<имя-space>.hf.space`.
6. Войдите администратором, в разделе «Модели и анализ» выберите режим «Языковая модель (LLM)», сервис, модель (кнопка «Показать доступные модели») и сохраните.

## Что важно знать

- **Данные не сохраняются.** На бесплатном Space диск временный: после перезапуска пропадают пользователи, уроки и настройки, демо-данные создаются заново.
  Для постоянного хранилища нужен платный Persistent Storage или внешняя база.
- **Скорость.** На 2 vCPU распознавание Whisper small идёт примерно в реальном времени записи или медленнее. Для демонстрации используйте короткие записи (1–3 минуты)
  и модель `small` или `base`. Видеокарты на бесплатном тарифе нет.
- **Сон.** Бесплатный Space засыпает после неактивности и просыпается за минуту при заходе.
- **Безопасность.** Не оставляйте публичным Space с включённым демо-входом и ключом LLM: любой посетитель сможет зайти администратором. Для публичной ссылки задайте `DATERA_DEMO=0` и свой `DATERA_PASSWORD`.

## Запуск на своём компьютере

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt     # нужен ffmpeg в PATH (macOS: brew install ffmpeg)
.venv/bin/uvicorn web.server:app --port 8501
```

Откройте http://localhost:8501. Демо-аккаунты создаются при первом запуске, пароли записываются в `seed.json`; кнопки демо-входа есть на странице входа.

## Через Docker

```bash
docker build -t datera-edu .
docker run -p 7860:7860 -e DATERA_PASSWORD=ваш-пароль datera-edu
```

Откройте http://localhost:7860.
