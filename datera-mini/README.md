# DATERA EDU mini

Мини-версия дипломного проекта DATERA EDU для Final по Machine Learning.

На вход: запись (аудио или видео) и презентация. На выход: отчёт о том, какие темы
презентации прозвучали в записи, с индексом, цветовым статусом и тайм-кодами.

## Какие нейросети используются

| Этап | Модель | Что делает |
| :-- | :-- | :-- |
| Распознавание речи | **OpenAI Whisper** (Transformer энкодер-декодер, пакет `openai-whisper`, PyTorch) | Лог-мел-спектрограмма → текст с тайм-кодами, язык определяется автоматически |
| Анализ | `paraphrase-multilingual-MiniLM-L12-v2` (Transformer-энкодер, 118 млн параметров) | Пункт слайда и фрагмент речи → векторы; близкие по смыслу тексты дают близкие векторы, в том числе на разных языках |

Обе модели готовые (pre-trained), как и в MVP диплома. Все числа (индекс, статус) считает обычный код,
а не нейросеть: это решение из архитектуры диплома («rules instead of the language model for numbers»).

## Как это работает

```
видео / аудио ──ffmpeg──▶ WAV моно 16 кГц ──Whisper──▶ предложения с тайм-кодами ─┐
                                                                                   ├─▶ эмбеддинги ─▶ косинусное сходство ─▶ индекс и отчёт
презентация (.pptx / .pdf) ──▶ слайд = тема, пункт слайда = ключевой пункт ────────┘
```

1. **Этап 0, подготовка** ([datera/audio.py](datera/audio.py)). ffmpeg достаёт звук из видео, переводит в моно 16 кГц и выравнивает громкость.
2. **Этап 2, распознавание** ([datera/asr.py](datera/asr.py)). Whisper выдаёт сегменты с тайм-кодами, они склеиваются в целые предложения.
3. **Материалы** ([datera/materials.py](datera/materials.py)). Один слайд (или страница PDF) считается темой, каждый пункт на нём ключевым пунктом.
4. **Этап 4, анализ** ([datera/analysis.py](datera/analysis.py)). Пункт считается раскрытым, если его сходство с каким-то фрагментом речи не ниже порога (по умолчанию 0.65).
   Индекс темы = доля раскрытых пунктов. Цвета как в ТЗ (таблица 8): ниже 50 % красный, 50-79 % жёлтый, от 80 % зелёный.
   Речь, не похожая ни на один пункт, попадает в блок «Вне материала» (FR-7.8).
5. **Этап 5, отчёт** ([datera/report.py](datera/report.py)). Сводка, карта тем, разбор по пунктам с цитатами и тайм-кодами, транскрипт.

## Что взято из диплома, а что упрощено

| В дипломе | В мини-версии |
| :-- | :-- |
| faster-whisper large-v3 на GPU | оригинальный OpenAI Whisper, размер выбирается (по умолчанию `small`, работает на CPU) |
| Темы предлагает LLM, преподаватель подтверждает | тема = слайд, без LLM |
| LLM проверяет ответы ученика по материалу | сравнение смысла через эмбеддинги: прозвучал пункт или нет |
| Диаризация (pyannote), шумоподавление | нет |
| Три отчёта (преподаватель, ученик, родитель) | два: учителю и ученику, текст по шаблону без LLM |
| Go API, RabbitMQ, PostgreSQL, React | FastAPI, очередь в памяти, SQLite, страница на JavaScript |

Ограничение: система проверяет, **прозвучала** ли тема, а не **правильно** ли её объяснили. Проверка правильности в дипломе делается через LLM.

## Анализ языковой моделью (LLM)

По умолчанию ответы сверяются с материалом через эмбеддинги (без ключа и интернета). Администратор может
переключить анализ на языковую модель: кабинет «Администратор» → «Модели и анализ».

| Сервис | Модели | Ключ |
| :-- | :-- | :-- |
| Groq | открытые Llama | console.groq.com/keys |
| OpenRouter | много открытых, часть с пометкой `:free` | openrouter.ai/keys |
| Cerebras | открытые Llama | cloud.cerebras.ai |
| Together AI | Llama, Qwen, DeepSeek | api.together.ai |
| Mistral | открытые и закрытые модели Mistral | console.mistral.ai |
| Ollama | любая открытая модель на этом компьютере | не нужен |
| Google Gemini, OpenAI, Anthropic | закрытые модели | у каждого свой |

Условия бесплатных тарифов и названия моделей у сервисов меняются: кнопка «Показать доступные модели»
запрашивает актуальный список, «Проверить подключение» делает пробный запрос.

Как устроен анализ ([datera/llm_analysis.py](datera/llm_analysis.py)):

1. Расшифровка делится на реплики с номерами и ролями, имена заменяются метками «Ученик» и «Преподаватель» (FR-7.6).
2. Модель получает реплики и темы материала и возвращает JSON по фиксированной схеме (FR-7.5): по каждой теме
   номер вопроса, номер ответа, вердикт, комментарий; плюс тексты для учителя, ученика и родителя (FR-9.1).
3. Сервер проверяет каждую ссылку: ответ должен быть репликой ученика и идти после вопроса преподавателя.
   Тайм-коды и цитаты берутся из расшифровки, а не из ответа модели.
4. Индекс, цвет и карту знаний считает код. Если модель недоступна или трижды вернула негодный JSON,
   остаётся анализ по эмбеддингам, а в отчёте показывается причина.

Провайдер и модель меняются в настройках без правки кода (FR-7.7), версия модели и промпта сохраняется в уроке (FR-15.3).
Ключ хранится в `data/datera.db` на этом компьютере; вместо этого можно задать переменную `DATERA_LLM_API_KEY`.

## Веб-приложение: кабинеты учителя и ученика

Интерфейс свёрстан по макетам Figma «DATERA EDU - UI» (разделы «Преподаватель» и «Ученик»).
Сервер: FastAPI + SQLite ([web/server.py](web/server.py)), клиент: одна страница на чистом JavaScript ([web/static](web/static)).
Записи обрабатываются по очереди в фоновом потоке, поэтому загрузка не ждёт анализа.

| Кабинет | Экран (код в Figma) | Что работает |
| :-- | :-- | :-- |
| Учитель | Ученики (O1, O2) | список с индексом и красными темами, добавление ученика |
| Учитель | Карточка ученика (O7) | карта знаний с изменением между уроками, история уроков |
| Учитель | Предметы и материалы (O3, O4) | загрузка .pptx / .pdf, выделение тем, удаление лишней темы |
| Учитель | Загрузка записи (O5), Уроки (O6) | загрузка аудио или видео, статус по этапам, повтор при ошибке |
| Учитель | Отчёт по уроку (O8, O9) | плеер с переходом по тайм-коду, темы с доказательствами, «Подтвердить» и «Изменить» статус, конспект, «Вне материала», рекомендации |
| Учитель | Транскрипт (O10) | фразы с тайм-кодами и темой |
| Учитель | Как работает модель | спектрограмма, язык, уверенность, параметры сети (для защиты по ML) |
| Ученик | Мои уроки (S1) | «Что повторить», сводка по темам, карточки уроков |
| Ученик | Отчёт по уроку (S2) | плеер, «Что получилось», «Что стоит повторить» |
| Ученик | Карта знаний (S3) | три колонки: нужно повторить, почти получилось, получается |

| Учитель | Отчёт по уроку, три вида | «По ходу урока» (вопрос → ответ по тайм-кодам), «По темам», «Отчёты для ролей» |
| Учитель | Транскрипт и говорящие (O10, O10C) | роли по голосу, «Поменять роли местами» |
| Родитель | Уроки ребёнка, отчёт, карта знаний | короткий отчёт без терминов, «Как помочь дома» |
| Администратор | Модели и анализ | размер Whisper, язык, LLM или эмбеддинги, сервис, модель, ключ, проверка связи |
| Администратор | Очередь и ошибки | статус, модели и время по каждому уроку, повторная обработка |

Не сделано: команда, настройки профиля, контрольный урок, тесты и недельные сводки (этап 2), мобильные макеты.

Тема считается затронутой на уроке, если прозвучал хотя бы один её пункт. Незатронутые темы не оцениваются
и не меняют карту знаний. Если учитель меняет статус, индекс и карта пересчитываются (FR-8.7).

## Запуск

Нужны Python 3.10+ и ffmpeg (`brew install ffmpeg`).

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
```

Веб-приложение (откроется на http://localhost:8501):

```bash
.venv/bin/uvicorn web.server:app --port 8501
```

При первом запуске создаются демо-аккаунты учителя, ученика, родителя и администратора (почта и пароль лежат в `seed.json`),
предмет «Нейронные сети» и урок из папки `sample/`. На странице входа есть кнопки демо-доступа.
Данные хранятся в папке `data/`; чтобы начать с нуля, удалите её.

Командная строка без кабинетов (отчёт сохранится в папку `out/`):

```bash
.venv/bin/python cli.py sample/talk.m4a sample/slides.pptx --model small
```

При первом запуске модели скачиваются сами: Whisper `small` 461 МБ, модель эмбеддингов около 470 МБ.
Размер модели Whisper и способ анализа меняются в кабинете администратора.

## Размер модели Whisper

| Модель | Параметры | Когда брать |
| :-- | :-- | :-- |
| `tiny`, `base` | 39 и 74 млн | быстро показать, качество на русском слабое |
| `small` | 244 млн | по умолчанию |
| `medium` | 769 млн | точнее, в несколько раз медленнее |
| `turbo`, `large-v3` | 809 и 1550 млн | лучшее качество; на CPU медленно |

## Тестовый пример

В папке `sample/` лежит презентация из 5 слайдов и минутная запись (синтезированный голос), сделанные скриптом
[sample/make_sample.py](sample/make_sample.py). В записи намеренно пропущен слайд про свёрточные сети,
не сказан один пункт про переобучение и вставлен рассказ про рыбалку. Ожидаемый и полученный результат:
слайды 2 и 3 зелёные (100 %), слайд 4 жёлтый (67 %), слайд 5 красный (0 %), рыбалка в блоке «Вне материала».

## Дообученный Whisper и его проверка

Папка рядом с этим проектом, `../whisper-finetune/`, содержит обучение: Whisper-base дообучен на русской речи (датасет FLEURS). Подробности, цифры и код: `../whisper-finetune/README.md`.

В приложении дообученную модель можно проверить двумя способами:

1. **Страница «Проверка Whisper»** (кабинет учителя и администратора): одна и та же запись проходит через обычный Whisper-base и через дообученный, рядом показаны тексты, время и доля ошибочных слов (WER), если известен правильный текст. Есть примеры из теста FLEURS (где дообучение помогло больше всего и где стало хуже, с цифрами «было → стало») и загрузка своей записи (до 3 минут). Блок **«Две записи, две модели»** сравнивает две записи с разными моделями Whisper на одной странице: загрузите по записи в A и B, выберите модели и нажмите «Сравнить» (галочка «та же запись» прогоняет один звук через две модели). Красным отмечены расхождения. Галочка «разделить на преподавателя и ученика» (включена по умолчанию) показывает расшифровку репликами: кто задаёт вопросы и кто отвечает, роли определяются по голосам.
2. **Выбор модели для уроков:** «Модели и анализ» → «Распознавание речи: Whisper» → **base-ru, дообучена вами на русской речи**. Дальше урок обрабатывается как обычно.

Дообученная модель маленькая (74 млн параметров), для настоящих уроков лучше оставить large-v3. Выбор по умолчанию не менялся.

Запуск из папки проекта, окружение лежит в `../whisper-finetune/.venv`:

```bash
../whisper-finetune/.venv/bin/python -m uvicorn web.server:app --port 8501
```
